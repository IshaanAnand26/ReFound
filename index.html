Lost something?
ReFound helps it find its way back.

A Lost & Found management system written in C++ using object-oriented programming. Report lost and found items, search them, and let Smart Match connect the two.

Try the demo View C++ code

How it works

1. Report

A person reports a lost or found item with category, location and contact details.

2. Store

Each report is an object. All objects are kept in a list and saved to items.txt.

3. Smart Match

Lost and found reports are compared by shared words and category, and scored.

4. Return

Once the owner gets the item back, the report is marked as returned.
